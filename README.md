# The Most Boring Object, Reviewed in One Line

make.fun entry for [The Most Boring Object, Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3).

The program writes one funny, true one-line review of a boring everyday object
to `/output/entry.txt`:

> My dustpan collects everything except the thin line of dust it was bought to remove.

Run it with `python3 main.py` (honours `MAKEFUN_OUTPUT_DIR`, falls back to `/output`).
